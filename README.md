# NekoBox for PC

[![Build Status](https://github.com/Restia-Ashbell/nekobox/actions/workflows/build.yml/badge.svg)](https://github.com/Restia-Ashbell/nekobox/actions)
[![Latest Release](https://img.shields.io/github/v/release/Restia-Ashbell/nekobox?include_prereleases&label=release)](https://github.com/Restia-Ashbell/nekobox/releases)
[![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS%20%7C%20Linux-blue)](https://github.com/Restia-Ashbell/nekobox/releases)

A Qt-based cross-platform GUI proxy configuration manager powered by **sing-box** as backend.

> 💡 **Note:** This is a simple personally maintained fork of the original project. It aims to keep up with core updates, bug fixes, and cross-platform compatibility improvements.

## Proxy

- SOCKS (4/4a/5)
- HTTP(S)
- Shadowsocks
- ShadowsocksR
- VMess
- VLESS
- Trojan
- TUIC ( sing-box )
- NaïveProxy ( Custom Core )
- Hysteria ( Custom Core or sing-box )
- Hysteria2 ( Custom Core or sing-box )
- AnyTLS
- SSH
- WireGuard
- Custom Outbound
- Custom Config
- Custom Core

## Subscription

- Raw: some widely used formats (like Shadowsocks, Clash and v2rayN)
